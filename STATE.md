# Markets Recon / Allocator Pro POC - State

_Last updated: 2026-10-25_

## Current State

Markets Recon is a local-first POC producing reviewable O/N/U/UNCERTAIN allocation calls against the 396-leaf locked taxonomy in `excel-file/Asset Class List - Locked.csv`; code validates evidence, fills taxonomy parents, scores confidence and assembles outputs, while models extract and review categorically. `src/run.py` accepts at most 20 sources; optional reconciliation and reader summaries run separately. The July master remains frozen at `client-runs/master-combined-15072026/`, including its October client export and five human decisions. Client output uses structured commentary, single-line BOM CSV and an XLSX twin; review flags represent judgments rather than every Medium confidence cap. The October intake has 16 preserved Markdown/PDF pairs, with 15 eligible sources in three five-source splits; source URLs are blank, dates come from documents only, State Street Sector Market Perspectives retains 06/10/2026, and L&G's Q4 2024 edition is excluded. Markdown is the primary input, augmented only by inventory-flagged paired-PDF chunks: each validates against its own source view, PDF evidence carries `(read from PDF)`, and pagecheck runs before export. The quality revision distinguishes adopted positions from analytical inputs, binds source/chunk IDs in code, segregates forecast-based inferences and disables interactive hooks only in headless Codex processes. All three final focused controls passed on one fingerprinted checkout that predates the merged #6 review fixes (`assemble`, `pagecheck`, `run`, `scout`: page-reference parsing, lazy PDF page re-read) and the PR review prompt clarifications (`conventions`, `analyze_chunk`, `check_candidates`, `arbitrate_conflict`, `crosscheck_conflicts`: wording only, but read by the run), so the launcher reports that drift and each split's manifest records its own provenance; revised full splits remain for the user to launch after reviewing `docs/run-records/oct2026-quality-validation.md` and `docs/run-records/oct2026-md-run-commands.md`.
