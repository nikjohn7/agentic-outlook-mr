# Markets Recon / Allocator Pro POC - State

_Last updated: 2026-10-25_

## Current State

Markets Recon is a local-first POC that converts asset-manager outlooks into reviewable O/N/U/UNCERTAIN calls using the locked taxonomy in `excel-file/Asset Class List - Locked.csv`; normalization, taxonomy validation, evidence gates, confidence scoring and assembly are deterministic, with LLMs used for extraction and categorical review. `src/run.py` processes at most 20 sources per run; `src/reconcile.py` combines firm-level calls, and `src/summarize.py` produces optional digests, firm pages and a Word binder (digest claude/claude-sonnet-5-5/medium, firmpages claude/claude-sonnet-5-5/high). The July deliverable is frozen at `client-runs/master-combined-15072026/`: original internal output has 3,767 rows across 150 firms, 1,401 client failure rows and 150 firm pages plus binder; its October `client-export/` has 3,739 output rows, 1,429 failure rows and 641 review rows, with the five July human decisions preserved. Client exports now contain structured commentary, BOM-prefixed single-line UTF-8 CSV and an XLSX twin, while review flags indicate judgments rather than every confidence cap; the shared-evidence gate runs by default on new runs and was never run on the frozen July master. The feedback PR is merged (`main` at `740a73a`, synced with origin). The new evaluation intake contains 16 Markdown/PDF pairs (251 PDF pages) under `client-inputs/2026-10-review/`, indexed with exact paths and SHA-256 hashes in `client-runs/runs-23102026-16rows/intake-manifest.json`; source files are preserved; only a Markdown-only trial of split 1 has run. Initial inspection confirmed lost visual allocation information, inconsistent page references and extraction noise; these documents are source evidence, with client-approved benchmark interpretations still to be established. The client's own engine produces the Markdown, so Markdown is the certain production input. The Markdown + PDF mode is built and documented (runbook 1.7): a source CSV row with a Markdown `local_file` and a `pdf_file` is read as the Markdown plus only the PDF pages a deterministic inventory flags (`pdf:` chunks, validated against the PDF only), PDF-read passages end their Locator with `(read from PDF)` (internal `evidence_origin`), and the page check runs inside every run. Operational references are `docs/PIPELINE_RUNBOOK.md`, `docs/run-records/`, `ARCHIVE_INDEX.md` and batch handoffs; the test command is `.venv/bin/python -m unittest discover -s tests`.
