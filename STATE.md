# Markets Recon / Allocator Pro POC - State

_Last updated: 2026-10-23_

## Current State

Markets Recon is a local-first POC that ingests fund and asset-manager outlook documents and produces reviewable O/N/U/UNCERTAIN sub-asset-class calls against the locked taxonomy in `excel-file/Asset Class List - Locked.csv`. The pipeline is deterministic for ingestion normalization, taxonomy lookup, evidence validation, confidence scoring, assembly, date handling, and reconciliation; LLM calls are limited to extraction and categorical review. `src/run.py` processes up to 20 sources per run with per-step engine/model/effort defaults, and `src/reconcile.py` produces the final firm-level output from dated batch outputs. Reader summaries use `src/summarize.py`: `digest` and `firmpages` both default to `claude/claude-sonnet-5/high`, then `bind` produces the Word document deterministically. Both production batches (98-row and 145-row) are complete and combined into one human-reviewed master deliverable, `client-runs/master-combined-15072026/` (3,767 output rows, 150 firms, 1,401 client failure rows, 150 firm pages + Word binder), delivered to the client in July 2026. The client-facing shape is now produced by `src/export.py` (structured commentary columns, no internal diagnostics, BOM-prefixed UTF-8 + `.xlsx` twin) and written automatically next to every `output.csv`; `src/sharedevidence.py` is the in-run (and post-hoc) gate that keeps only the most compelling call(s) when one passage is cited for several sub-asset classes. Authoritative operational instructions are in `docs/PIPELINE_RUNBOOK.md`, `docs/run-records/`, and the batch handoff files. Run the test suite with `.venv/bin/python -m unittest discover -s tests`.
